## موانع آزمون عملیاتی

هنگام بررسی این نسخه، مسیر config روی Stage به جای JSON صفحه HTML با عنوان Maintenance برگرداند. اتصال مدیریتی Stage نیز درخواست احراز هویت مجدد دارد. هیچ تغییر سرور یا دیتابیس برای رفع این وضعیت انجام نشده است.
آزمون محلی رابط کاربری، آزمون ثبت سفارش و ورود واقعی محسوب نمی‌شود.

## مواردی که نباید کامل اعلام شوند

- فارسی/انگلیسی تمام برنامه: فعلاً بخش ورود دو زبانه است؛ صفحات بعد از ورود کامل ترجمه نشده‌اند.
- ورود با رمز و گوگل: قرارداد و زیرساخت واقعی باید در Stage بررسی و آزموده شود.
- مدل‌های وابسته به برند، ظرفیت واقعی و قیمت‌ها: به قرارداد Core وابسته‌اند؛ داده ساختگی جایگزین نمی‌شود.
- تیکت، چت، فروشگاه‌ها، ایمیل تأیید و ایمیل رسید: UI و درخواست‌های اتصال موجود، اما آزمون زنده انجام نشده است.
- پروفایل: برخی ویرایش‌ها فقط روی گوشی ذخیره می‌شوند؛ همگام‌سازی کامل نیازمند API واقعی است.
- چرخه مشتری تا تکنسین و مالی: بدون آزمون End-to-End قابل تأیید نیست.
