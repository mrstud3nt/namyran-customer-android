# نامزد آزمایشی مشتری 0.5.2 و Bridge 0.3.0

این بسته نسخه نهایی تأییدشده برای انتشار عمومی نیست. هیچ Migration یا فعال‌سازی خودکار ندارد. Production و Stage فعلی نباید تغییر کنند.

- APK با پسوند clone2 فقط به clone2.namyranservice.ir وصل می‌شود و شناسه نصب جداگانه دارد. امکان برگشت خودکار به Stage یا Production ندارد.
- بسته Bridge از همان Commit در CI تولید می‌شود. فایل ZIP قدیمی از سورس حذف شده تا نصب اشتباه رخ ندهد.
- پشتیبانی مشتری: ثبت تیکت، فهرست تیکت‌های متعلق به صاحب نشست OTP، مشاهده پیام‌ها و پاسخ به تیکت باز. تکرار درخواست با همان کلید، رکورد تکراری ایجاد نمی‌کند؛ تغییر متن با همان کلید رد می‌شود.
- تیکت‌ها از نوشته‌ها و دیدگاه‌های خصوصی WordPress استفاده می‌کنند؛ جدول جدید ایجاد نمی‌شود. هر چهار جدول posts/postmeta/comments/commentmeta باید InnoDB باشند. در غیر این صورت نوشتن با 503 متوقف می‌شود.
- مدیر دارای manage_options از منوی «تیکت‌های مشتریان نامیران» تیکت را می‌خواند و از دیدگاه همان نوشته پاسخ می‌دهد. بستن بخش دیدگاه، پاسخ جدید مشتری را می‌بندد. هیچ شماره موبایل، Token یا Secret در محتوای تیکت یا پاسخ API ثبت نمی‌شود.
- قابلیت چت آنلاین تا وجود اتصال واقعی کارشناس، online=false می‌دهد و کاربر می‌تواند تیکت بسازد. مسیر فروشگاه‌های همکار هنوز در این بسته Backend معتبر ندارد. ورود اصلی OTP است؛ ورود مستقل با رمز فعال نشده است.

## پیش از نصب یا فعال‌سازی روی Clone2

ایزوله‌بودن پیامک، ایمیل، پرداخت، اعلان، حافظه مشترک و Cron، اتصال به دیتابیس اختصاصی و بکاپ/روش بازگردانی باید روی میزبان تأیید شود. محافظت Directory Privacy حذف نمی‌شود؛ اگر برنامه با 401 محافظ میزبان روبه‌رو شود، اعتبارنامه آن نباید در APK یا مخزن ذخیره شود. تست OTP و چرخه مأموریت نیازمند نشست مجاز و دسترسی محیط ایزوله است.

تست‌های محلی با fixture رفتار کنترلر را بررسی می‌کنند و جای تست WordPress/MySQL واقعی را نمی‌گیرند. نصب این بسته روی میزبان در این مرحله انجام نشده است.
